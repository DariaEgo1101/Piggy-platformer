# Свинка-копилка — охота за монетами

## 1. Описание проекта

«Свинка-копилка — охота за монетами» — это небольшой двухмерный платформер, разработанный с использованием HTML, CSS и JavaScript Canvas.

**Цель игры:** управляя свинкой, собрать три монеты, избегать опасной зоны и добраться до финиша.

### Основные возможности

- Движение персонажа влево и вправо.
- Прыжки с учётом гравитации.
- Столкновения с платформами.
- Сбор монет и подсчёт очков.
- Опасная зона и условие поражения.
- Условие победы после сбора всех монет и достижения финиша.
- Пауза, продолжение игры и перезапуск.
- Сохранение рекорда в `localStorage`.
- Сенсорное управление для мобильных устройств.
- Мультяшная графика, созданная средствами Canvas.

## 2. Технологии

- **HTML5** — структура страницы и игровое поле.
- **CSS3** — оформление интерфейса и адаптация под мобильные устройства.
- **JavaScript (ES Modules)** — игровая логика, физика и управление.
- **Canvas API** — отрисовка персонажа, платформ, монет и игрового окружения.
- **localStorage** — сохранение лучшего результата.
- **AI-помощник ChatGPT** — помощь в разработке, организации кода, реализации игровой механики и подготовке документации.

В проекте не используются игровые движки, npm и системы сборки.

## 4. Запуск проекта

1. Скопировать файлы проекта в одну папку.
2. Открыть папку в Visual Studio Code.
3. Установить расширение Live Server, если оно ещё не установлено.
4. Открыть файл `index.html`.
5. Нажать правой кнопкой мыши и выбрать **Open with Live Server**.
6. Игра откроется в браузере.

**Важно:** поскольку проект использует ES-модули JavaScript, рекомендуется запускать его через локальный сервер, а не напрямую через `file://`.

## 5. Управление

| Клавиша или кнопка | Действие |
|---|---|
| Стрелка влево / A | Движение влево |
| Стрелка вправо / D | Движение вправо |
| Space / W | Прыжок |
| P | Пауза |
| Старт | Начать новую игру |
| Пауза | Приостановить игру |
| Продолжить | Возобновить игру |
| Заново | Сбросить игровой прогресс |

На мобильных устройствах используются экранные кнопки влево, вправо и прыжок.

## 6. Правила игры

1. Управлять свинкой с помощью клавиатуры или сенсорных кнопок.
2. Собирать три монеты, расположенные на уровне.
3. Перепрыгивать между платформами.
4. Избегать опасной зоны и не падать за пределы уровня.
5. После сбора всех монет добраться до финиша.

**Победа:** собраны все три монеты и достигнут финиш.

**Поражение:** персонаж касается опасной зоны или падает за пределы уровня.

После завершения игры можно начать заново. Лучший результат сохраняется между перезагрузками страницы, если браузер разрешает использование `localStorage`.

## 8. Примеры промптов для нейросети

### Промпт 1. Создание основы игры

> Создай небольшой платформер «Свинка-копилка бегает за монетами» на HTML, CSS и ванильном JavaScript с Canvas. Используй ES-модули и раздели код на index.html, style.css, main.js, Game.js, Player.js, input.js и collision.js. Не используй игровые движки, npm и сборку. Начни с рабочего Canvas, персонажа, земли и подсказок управления.

### Промпт 2. Реализация физики и столкновений

> Добавь движение персонажа стрелками или A/D, прыжок Space/W и гравитацию. Измеряй скорость в пикселях в секунду, передавай dt в обновление. Реализуй столкновения с платформами сверху, сбоку и снизу с учётом предыдущего положения персонажа. Сохрани модульную структуру и выдай полные версии изменённых файлов.

### Промпт 3. Игровая цель и состояния

> Добавь три собираемые монеты, счёт, опасную зону и финиш. Монета должна исчезать после сбора и начислять одно очко. Победа наступает после сбора всех монет и достижения финиша, поражение — при падении или столкновении с опасностью. Добавь паузу, продолжение, рестарт и сохранение рекорда в localStorage с обработкой ошибок.

### Промпт 4. Адаптивный интерфейс

> Улучши графику платформера в милом мультяшном стиле. Нарисуй фон, персонажа, платформы и монеты средствами Canvas, без внешних изображений. Добавь сенсорные кнопки движения и прыжка для мобильных устройств. Сохрани управление с клавиатуры, физику, игровые координаты и структуру ES-модулей.

### Промпт 5. Проверка и исправление ошибок

> Проверь код платформера на ошибки в физике, столкновениях, игровом цикле и обработке состояний. Найди причину каждой обнаруженной проблемы, исправь её без нарушения дизайна и существующих правил игры. Выдай полные изменённые файлы и предложи короткий список действий для проверки исправлений.
